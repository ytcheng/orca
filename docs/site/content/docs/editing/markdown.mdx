---
title: Markdown in Orca
---

Markdown files open in Orca's native Reader by default. It renders headings, tables, code blocks, math, and Mermaid, PlantUML, and Graphviz diagrams. Use the Reader toolbar to show the table of contents or search rendered text. Check task-list items directly in the document, and click an image or diagram to zoom and pan it. Use the view switcher to open the same file in **Source** or **Rich Editor**; each tab keeps its selected view.

The Rich Editor includes a slash menu, formatting toolbar, inline image and code previews, and internal link autocomplete.

Files larger than 600 KiB still open in Reader, while Rich Editor stays in Source mode to keep typing responsive. Choose **Open anyway** in the fallback banner to use Rich Editor for that file; the choice lasts until you close its tab. Markdown constructs that Rich Editor cannot safely preserve stay in Source mode, while Reader remains available.

## Slash menu

Type `/` on an empty line to open the slash menu: headings, lists, code blocks, callouts, images, mermaid diagrams, and toggle blocks.

Use `/toggle-text` for collapsible notes, or `/toggle-h1` … `/toggle-h5` when the toggle summary should read like a heading level. You can edit nested toggles in place. Orca saves toggles as portable `<details>` / `<summary>` markdown so the file still previews outside Orca.

## Internal links

Type `[[` to start a wiki-style link. Orca autocompletes file paths within the worktree and inserts a relative link.

## Search

Reader search respects rendered text, not raw markdown — so searching for "Install" finds a heading whether written as `# Install` or `<h1>Install</h1>`.

## Review annotations

When you're reviewing markdown in Orca's rich editor, select rendered text to add an annotation without switching back to raw markdown. Orca keeps the note tied to the selected source range so it can show the comment while you continue editing the rendered document.

**Add Review Note** is a remappable shortcut (`Cmd+Shift+A` / `Ctrl+Shift+A` by default under [Settings → Shortcuts](/docs/settings)).

## Front matter

YAML and TOML front matter is shown in the Rich Editor and Reader by default so docs and static-site posts expose their metadata without switching to Source. Open the editor's **More actions** (`…`) menu and choose **Hide front matter** when you want the body-only view; the same menu toggles it back to **Show front matter**. The toggle is per-file, so hiding it on one document doesn't hide it on the rest.

## Tables

In rich markdown tables:

| Key                                                           | Behavior                                                   |
| ------------------------------------------------------------- | ---------------------------------------------------------- |
| **Tab** / **Shift-Tab**                                       | Next / previous cell; Tab past the last cell inserts a row |
| **Enter**                                                     | Move to the cell below; on the last row, add a row         |
| **Backspace** on a fully empty row                            | Delete the row (or the whole table if it is the last row)  |
| **Backspace** in an empty cell when the row still has content | Step to the previous cell                                  |

Use **Shift-Tab** to unindent a list item or the selected lines of a code block.

When the caret is in a table, the rich-editor toolbar shows one-click **row and column insert/delete** controls. Right-click a table cell for the same structure commands in the context menu (the Table submenu only appears when the target is a table cell).

## Table of contents

For long documents, use the **Table of Contents** button (tree icon) in the Reader toolbar or editor header to show a heading outline pinned to the left of the editor. Clicking a heading jumps to it; collapse and expand controls keep deeply nested sections readable. The outline is available in Reader and Rich Editor.

## Share as artifact

From the editor header, **Share as artifact** publishes the open Markdown file as a public view link through your signed-in Orca account. Requires **Settings → Artifacts → Allow publishing public artifact links** (off by default). Republish updates the same link when Orca still has the mapping; manage or delete links from the sidebar **Artifacts** page. Agents and scripts can use `orca artifacts share|update|list|delete` — see [CLI reference → Artifacts](/docs/cli/reference#artifacts).
